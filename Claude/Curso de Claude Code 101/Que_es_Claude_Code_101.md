<h2> Claude Code 101 </h2>

<p align="left"> 

Una herramienta de codificación agéntica que vive en tu terminal. Aprende qué es Claude Code, cómo funciona y los flujos de trabajo principales para realizar trabajo real con ella.

Objetivos:
* Explicar qué es un agente de codificación de IA y en qué se diferencia Claude Code de las herramientas de IA basadas en chat
* Comprender cómo funcionan juntos el bucle agéntico, la ventana de contexto, las herramientas y los permisos
* Instalar y configurar Claude Code en la terminal, VS Code, JetBrains, Claude Desktop o en la web
* Escribir prompts efectivos usando el modo manual, la aceptación automática y el Modo Plan
* Seguir el flujo de trabajo Explorar → Planificar → Codificar → Confirmar para cualquier función o tarea
* Gestionar tu ventana de contexto con /compact, /clear y /context para mantenerte productivo
* Crear y mantener un archivo CLAUDE.md para darle a Claude memoria persistente del proyecto
* Crear subagentes personalizados para delegar tareas y mantener limpio tu contexto principal
* Conectar herramientas externas y fuentes de datos usando servidores MCP
* Escribir hooks para un control determinista sobre el formato, el bloqueo de comandos y las notificaciones
</p>

<h3> Claude Code 101 </h3>

<p align="left"> Los agentes de codificación de IA están cambiando lo que significa escribir software. Tareas que antes tomaban una tarde — rastrear un error en una base de código grande, crear la estructura de un nuevo servicio, revisar una pila de pull requests — ahora pueden suceder en una sola sesión enfocada, con un agente que lee tu código, ejecuta tus comandos y edita archivos junto a ti. Pero obtener un valor real de un agente requiere más que instalarlo y escribir una solicitud. Requiere entender cómo piensa el agente, a qué contexto tiene acceso y cómo guiarlo cuando se dirige en la dirección equivocada.

Este curso enseña a los desarrolladores cómo usar Claude Code de manera efectiva, ya seas nuevo en la ingeniería de software o un ingeniero experimentado que aún no ha trabajado con agentes de codificación de IA. Comenzamos desde los primeros principios — qué es realmente un bucle agéntico, cómo la ventana de contexto determina lo que Claude puede ver, cómo las herramientas y los permisos determinan lo que puede hacer — para que las técnicas más adelante en el curso tengan sentido en lugar de sentirse como una lista de trucos para memorizar.

Aprenderás a instalar Claude Code en múltiples entornos (terminal, VS Code, JetBrains, Claude Desktop y la web), y cómo escribir prompts que obtengan buenos resultados en el primer intento usando el modo de aprobación, la aceptación automática y el Modo Plan. El núcleo del curso es el flujo de trabajo Explorar → Planificar → Codificar → Confirmar: un ritmo repetible para desglosar una tarea, dejar que Claude proponga un enfoque, revisar el trabajo a medida que sucede y finalizarlo de forma limpia. También cubrimos la revisión de código con Claude Code y los comandos de gestión de contexto (/compact, /clear, /context) que mantienen productivas las sesiones largas.

La sección final trata sobre hacer que Claude Code sea tuyo. Escribirás un archivo CLAUDE.md para que Claude recuerde las convenciones de tu proyecto entre sesiones, crearás subagentes personalizados y skills para las tareas que repites con frecuencia, conectarás sistemas externos mediante servidores MCP y escribirás hooks que agreguen barreras de protección deterministas alrededor de lo que Claude tiene permitido hacer. Al final, tendrás una configuración adaptada a cómo realmente trabajas, no una instalación genérica.</p>
