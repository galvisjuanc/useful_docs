<h2> ¿Qué es Claude Code? </h2>

<p align="left"> Claude Code es una herramienta de codificación agéntica que comprende tu base de código, edita tus archivos, ejecuta comandos y se integra con tus herramientas de desarrollo existentes para ayudarte a hacer las cosas más rápido. Está disponible en tu terminal, Visual Studio Code, la aplicación Claude Desktop, en la web y en los IDE de JetBrains. </p>

<h3> ¿Qué diferencia Claude Code de Claude? </h3>

<p align="left"> Si has usado Claude.ai antes, quizás te preguntes qué hace diferente a Claude Code. A diferencia de Claude.ai, Claude Code tiene acceso directo a tus archivos, tu terminal y toda tu base de código. En lugar de copiar y pegar código de un lado a otro, entra y hace el trabajo por sí mismo.


El diferenciador clave es que Claude Code funciona como un Agente de IA. </p>

<h3> ¿Qué es un Agente? </h3>

<p align="left"> Un Agente de IA es software que puede interactuar con su entorno y realizar acciones para completar un objetivo definido. En esencia, esto funciona al tener un modelo de lenguaje grande operando en un bucle en tiempo real. Los Agentes de IA pueden tener acceso a herramientas, servicios externos o incluso a otros Agentes de IA para ayudar a alcanzar sus objetivos. </p>

<h3> ¿Qué puede hacer realmente Claude Code? </h3>

<p align="left"> Esto es lo que eso significa en la práctica:

* Leer y comprender tu base de código. Puedes pedirle a Claude Code que explique una función o rastree un error en todo tu código.
* Editar archivos en todo tu proyecto. Claude Code puede refactorizar una función y actualizar cada archivo que la referencia.
* Ejecutar comandos de terminal. Puede ejecutar tu script de compilación, correr tus pruebas, instalar paquetes y usar el resultado para decidir qué hacer a continuación.
* Buscar en la web. Si necesita documentación o las últimas referencias de API, puede buscarlas por ti. </p>

<h3> Usar Claude Code de manera efectiva </h3>

<p align="left"> Para usar Claude Code de manera efectiva, ten en cuenta estos tres conceptos:

* La ventana de contexto. Piensa en esto como la memoria de trabajo de Claude. Puede contener mucho, pero no todo a la vez. Aquí es donde entra el aspecto "agéntico": Claude encuentra formas estratégicas de localizar respuestas dentro de tu base de código sin cargar todo en el contexto.

* Tú controlas sus permisos. Los modos de permisos de Claude Code te permiten elegir qué tan involucrado quieres estar: puede pedirte confirmación antes de ejecutar comandos o hacer cambios, o ejecutarse en modo automático, donde una verificación de seguridad en segundo plano filtra la mayoría de las acciones en su lugar. Siempre tienes el control, ya sea que prefieras un enfoque más práctico o más autónomo.

* Puede cometer errores. Al igual que cualquier herramienta, Claude Code no es perfecto. Podría malinterpretar tu intención, introducir un error o sobrediseñar una solución. Mantenerte atento te ayuda a detectar estos problemas a tiempo. </p>
