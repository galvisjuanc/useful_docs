<h3>Navegando la aplicación de escritorio de Claude: Chat, Cowork, Code</h3>

<p align="left"> La aplicación de escritorio de Claude te ofrece tres formas de trabajar con Claude: Chat, Cowork y Code — desde preguntas rápidas hasta investigaciones complejas y la construcción de software.

Chat es el mismo Claude que conoces de claude.ai, además de entrada rápida, capturas de pantalla, dictado y conectores que provienen de ejecutarse de forma nativa en tu computadora. 

Cowork es una herramienta agéntica — le das un objetivo, la conectas a tus herramientas y recursos, y dejas que haga el trabajo. Con Cowork, Claude tiene el alcance y el espacio para hacer más. Este alcance más amplio le permite realizar investigaciones y análisis más exhaustivos, y producir documentos y entregables más complejos. 

Code es para construir software, desde escribir y probar código hasta implementarlo.

Cowork y Code se ejecutan en el mismo motor. Ambos son Claude Code por debajo — local en tu máquina, capaz de trabajo independiente, capaz de poner en marcha subagentes y sostener tareas largas. Esto permite que Claude trabaje en tareas más grandes por sí mismo, como investigación y redacción o construcción de software.

Cada modo está diseñado en torno al trabajo al que sirve, mostrándote lo que importa y dándote control donde lo necesitas.</p>
