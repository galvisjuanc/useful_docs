<h2> Otras formas de trabajar con Claude </h2>

<p align="left"> 

Objetivos:
* Comprender cuándo usar Claude Code, Claude Tag, Claude Design, Claude for Microsoft 365 y Claude in Chrome


Como mencionamos al inicio de este curso, Claude es una inteligencia. Claude.ai es solo una forma de trabajar con ella.

Claude también está disponible en varias herramientas especializadas diseñadas para encontrarte donde ya trabajas. Esta lección presenta formas adicionales de trabajar con Claude, cada una adaptada a flujos de trabajo y casos de uso específicos.
</p>

<h3> Claude Code </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude Code es una herramienta de codificación agéntica que funciona donde tú trabajas — en tu terminal, IDE, navegador, o incluso en Slack. Comprende tu base de código, ejecuta comandos y gestiona flujos de trabajo de desarrollo completos mediante lenguaje natural.

<strong> Cuándo usar Claude Code: </strong>

* Quieres construir funcionalidades describiendo lo que necesitas en lenguaje sencillo, y que Claude escriba el código, ejecute pruebas y cree commits
* Necesitas depurar problemas pegando mensajes de error y haciendo que Claude analice tu base de código para identificar y solucionar problemas
* Estás navegando por una base de código desconocida y quieres hacer preguntas sobre cómo funcionan juntas las diferentes partes
* Quieres automatizar tareas tediosas como corregir errores de lint, resolver conflictos de fusión o escribir notas de lanzamiento
* Prefieres trabajar en tu terminal junto a tu IDE y herramientas de desarrollo existentes en lugar de cambiar a una interfaz separada

</p>

<h3> Claude Tag </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude Tag lleva a Claude directamente a Slack, permitiéndote obtener ayuda en canales e hilos o traer contexto de Slack a tus conversaciones con Claude — solo etiqueta a Claude en cualquier hilo.

<strong> Cuándo usar Claude Tag: </strong>

* Quieres redactar respuestas a mensajes, resumir hilos extensos o desglosar discusiones complejas sin salir de Slack
* Necesitas prepararte para reuniones haciendo que Claude reúna conversaciones relevantes y documentos compartidos de tu espacio de trabajo
* Te estás incorporando a un nuevo equipo y quieres ayuda para entender proyectos en curso revisando el historial de canales
* Quieres transferir tareas de codificación directamente desde un informe de error o una discusión de funcionalidad—solo etiqueta a Claude y puede iniciar una sesión de Claude Code usando el contexto circundante
* Necesitas obtener respuestas rápidamente sobre tendencias de la industria, conceptos técnicos o información de la empresa durante una conversación
</p>

<h3> Claude Design </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude Design convierte ideas en interfaces funcionales. Describe lo que quieres en lenguaje sencillo — o parte de un boceto o captura de pantalla — y Claude construye un prototipo interactivo como un artefacto que puedes editar directamente, compartir con tu equipo o entregar a Claude Code para que lo construya. Funciona dentro de cualquier conversación con Claude y en la pestaña de Artifacts, y también está disponible como un espacio dedicado en claude.ai/design.

<strong> Cuándo usar Claude Design: </strong>

* Quieres pasar de un brief escrito, boceto o captura de pantalla de referencia a un prototipo de interfaz 
* Estás explorando direcciones de diseño y quieres generar y comparar varias variaciones rápidamente
* Necesitas iterar sobre el diseño, el texto o las interacciones sin editar el marcado — en el lienzo, con un comentario, o simplemente preguntando (la lección "Crear con artifacts" cubre la mecánica)
* Quieres un prototipo que use el sistema de diseño de tu equipo, para que lo que entregues coincida con lo que construirá ingeniería

        Disponibilidad

        Claude Design dentro de tus conversaciones está en beta y disponible en planes de pago (Pro, Max, Team y Enterprise). En Pro y Max está activado por defecto. En Team está activado por defecto, y un administrador puede desactivarlo. En Enterprise, un administrador lo activa en la configuración de la organización > Artifacts. El espacio independiente claude.ai/design tiene su propia configuración separada. La lección "Crear con artifacts" cubre cómo encaja junto a Claude Slides y Claude Docs.
</p>

<h3> Claude for Excel </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude for Excel lleva a Claude directamente a Microsoft Excel a través de una barra lateral, permitiéndote analizar, comprender y modificar hojas de cálculo mediante conversación.

<strong> Cuándo usar Claude for Excel: </strong>

* Estás trabajando con un libro complejo de varias pestañas y quieres entender cómo funcionan fórmulas específicas o flujos de cálculo entre hojas
* Necesitas actualizar supuestos o entradas en tu modelo mientras preservas las dependencias y relaciones de las fórmulas
* Estás depurando errores de hojas de cálculo como #REF!, #VALUE! o referencias circulares y quieres que Claude las rastree hasta su origen y sugiera soluciones
* Quieres crear nuevas hojas de cálculo o completar plantillas existentes con datos manteniendo una estructura de fórmulas adecuada
* Necesitas construir rápidamente tablas dinámicas o gráficos para visualizar tus datos
</p>

<h3> Claude for PowerPoint </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude for PowerPoint lleva a Claude a Microsoft PowerPoint como una barra lateral, para que puedas redactar, editar y reestructurar presentaciones mediante conversación mientras mantienes intactos tu plantilla y estilo de marca existentes.

<strong> Cuándo usar Claude for Powerpoint: </strong>

* Quieres convertir un esquema, documento o conjunto de notas en un primer borrador de presentación sin construir cada diapositiva a mano
* Necesitas reescribir o ajustar el texto de las diapositivas — acortando viñetas, añadiendo notas del orador, o ajustando el tono para una audiencia específica
* Estás reestructurando una presentación existente y quieres ayuda para reordenar secciones, dividir diapositivas densas o fusionar las que se superponen
* Quieres aplicar un formato consistente en toda la presentación — títulos, estilos de viñetas y diseños — sin corregir manualmente cada diapositiva
* Te gustaría obtener sugerencias visuales rápidas para una diapositiva, como qué diseño o tipo de gráfico se ajusta mejor al punto que estás planteando
</p>

<h3> Claude for Word </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude for Word lleva a Claude a Microsoft Word como una barra lateral, para que puedas redactar, revisar y reestructurar el documento que tienes abierto — trabajando con cambios rastreados y comentarios, y extrayendo contexto de fuentes conectadas para fundamentar lo que escribes.

<strong> Cuándo usar Claude for Word: </strong>

* Quieres convertir un esquema o notas preliminares en un primer borrador estructurado en la plantilla de tu equipo
* Necesitas revisar una sección — ajustar la redacción, adaptar el tono para un lector específico, o reestructurarla — sin salir del documento
* Estás respondiendo a comentarios de revisores y cambios rastreados y quieres ayuda para trabajarlos directamente en el documento
* Quieres que el borrador se fundamente en material de origen que has conectado, para que las afirmaciones del documento se puedan rastrear hasta su procedencia
</p>

<h3> Claude for Outlook </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude for Outlook lleva a Claude a tu bandeja de entrada como una barra lateral, para que puedas clasificar correos, redactar respuestas con contexto de hilos relacionados y tu calendario, y convertir una larga cadena de correos en un resumen claro o un conjunto de próximos pasos.

        Disponibilidad

        Claude for Outlook está actualmente en beta y se instala por separado de los demás complementos de Microsoft 365. Consulta Claude for Outlook para la configuración.
</p>

<h3> Claude in Chrome </h3>

<p align="left"> 

<strong> Descripcion </strong> 

Claude in Chrome es una extensión de navegador que añade a Claude como una barra lateral en Google Chrome. Puede observar en qué estás trabajando y realizar acciones directamente dentro de tu navegador.
       

<strong> Cuando usar Claude in Chrome: </strong>

* Quieres resumir artículos, trabajos de investigación o páginas web mientras navegas
* Necesitas ayuda para redactar respuestas de correo electrónico o gestionar tu bandeja de entrada
* Estás completando formularios repetitivos y quieres automatizar el proceso
* Quieres probar funcionalidades de un sitio web o navegar por flujos de trabajo de varios pasos sin hacer clic manualmente en cada paso
* Necesitas un asistente de navegación que mantenga el contexto mientras te mueves entre pestañas y tareas. Esto lo hace excelente para extraer contexto de herramientas internas especializadas, CRMs o paneles de control.

        Nota importante

        Claude in Chrome está disponible de forma general en todos los planes de pago (Pro, Max, Team y Enterprise); no está disponible en el plan gratuito. En los planes Team y Enterprise, los administradores pueden activarlo o desactivarlo para toda la organización y limitar a qué sitios puede acceder. Anthropic recomienda usarlo para tareas de bajo riesgo en sitios web de confianza. La extensión solicita permiso antes de realizar acciones de alto riesgo como realizar compras o compartir datos personales, y ciertas categorías de sitios web (servicios financieros, contenido para adultos) están bloqueadas por defecto.
</p>
