<h2> Creación de archivos: Word, PowerPoint, Excel </h2>

<p align="left"> ¿Quieres crear archivos Word, Excel y PowerPoint de máxima calidad sin gastar horas dando formato? Claude se enfoca en la productividad del trabajador de conocimiento y transforma tus datos en documentos editables y profesionales. Esto le sirve a cualquiera que trabaje con ofimática en su día a día.

La clave está en algo llamado skills: capacidades instaladas que funcionan como una receta que le indica a Claude cómo trabajar con cada tipo de archivo. Gracias a ellas, puedes pedirle un plan de marketing y recibir un Word formateado con estructura, colores y toda la información lista para usar. </p>

<h3> ¿Qué son las skills de Claude y cómo se activan? </h3>

<p align="left"> Lo primero es cargar los documentos y darle una instrucción clara. En la clase se cargan dos reportes: uno de Microsoft sobre economía y futuro del trabajo, y el último informe de Anthropic sobre adopción de inteligencia artificial [00:36].

Las skills son capacidades que le dicen a Claude cómo trabajar de cierta manera con un formato específico. Claude tiene una skill para Word, una para PowerPoint, una para Excel y algunas más.

Lo interesante es cómo se activan: siempre con una palabra clave. Si le pides trabajar con Excel, invoca la skill de Excel; si mencionas una presentación, invoca la de PowerPoint [02:00]. Puedes ver el proceso en pantalla cuando Claude "lee la skill" y te abre a la derecha su descripción e instrucciones de uso.

<strong> ¿Qué es una skill en Claude? </strong>
Es una capacidad instalada, tipo receta, que le indica cómo trabajar con un formato o proceso específico. Se activa con una palabra clave como "Excel" o "PowerPoint".

Más adelante existe una clase dedicada a las skills, donde también se enseña a crear las tuyas propias para procesos repetitivos que necesitan consistencia en el tiempo. </p>
